# Optional decision-analysis tools

Use only when complexity justifies them. Never produce a large framework for a small question.

## Weighted decision matrix

Define options, 3–6 non-overlapping criteria, weights totaling 100%, and grounded scores. Show sensitivity: would a reasonable change in weights reverse the result? Avoid invented numbers; qualitative comparisons are often better.

## Premortem

Assume the plan failed. List 3–5 plausible causes, early warning signals, and mitigations. Separate likely failures from merely imaginable catastrophes.

## Reversibility matrix

Classify actions as reversible/irreversible and low/high downside. Under uncertainty, prefer cheap, reversible experiments before expensive commitments.

## Expected value

Use only when probabilities and payoffs have a credible basis. Otherwise present scenarios and break-even thresholds, not pseudo-mathematical certainty.

## Decision log

Record: date, objective, options, evidence, key assumptions, recommendation, expected signals, review trigger. Useful for learning from outcomes without hindsight bias.

## Compact answer template

**Recommendation:** [conditional conclusion]

**Reasons:** [top evidence and tradeoffs]

**Main risk / uncertainty:** [load-bearing unknown]

**Next step:** [smallest informative action + success criterion]
