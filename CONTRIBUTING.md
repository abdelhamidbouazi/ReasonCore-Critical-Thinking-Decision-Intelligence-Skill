# Contributing to ReasonCore

Thank you for contributing. Please keep changes practical, model-agnostic, evidence-calibrated, and concise.

1. Open an issue describing the failure mode or proposed improvement.
2. Add or update a realistic evaluation case, including what a successful answer should do.
3. Modify the smallest relevant instruction or reference file.
4. Run `python scripts/validate.py` and review any changes for contradictory guidance.
5. In pull requests, describe expected benefits, risks, and regression cases. Do not claim measured improvements without sharing methodology and data.

Avoid model-specific marketing, fabricated citations, hidden chain-of-thought requests, unsafe professional advice, and excessive instructions that cause over-analysis.

All contributions are submitted under the repository's MIT license.
